# Contributing

## Development Guidelines

- Keep changes focused and easy to review.
- Follow existing Java naming and formatting conventions.
- Preserve existing automated tests.
- Run relevant tests before committing changes.
- Avoid committing generated build output, IDE configuration, or local log files.
- Use descriptive commit messages that explain the purpose of each change.

## Pull Requests

- Describe the purpose of the change.
- Summarize the files modified.
- Include relevant test results when applicable.
